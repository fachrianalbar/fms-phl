# Taste

## Communication
- Writes in casual/informal Indonesian and expects replies in Indonesian. Confidence: 0.75
- Gets overwhelmed by long explanations with multiple options and asks "what should I do now" — wants a single, concrete next action spelled out rather than a menu of alternatives. Confidence: 0.5

## Workflow
- Prefers the agent to just do the task end-to-end rather than hand back manual steps to run himself — will supply whatever's needed (e.g. a server password) and say "just access it". Confidence: 0.6
